Detailed Description

Strategy object for the modified augmented-Lagrangian (ModAL) Navier-Stokes preconditioner.

Supplies the approximate inverses the ModAL preconditioner needs: the inverses of the augmented velocity diagonal blocks (for each spatial dimension) and the inverse of the pressure Schur complement . The augmentation parameter and an optional pressure mass matrix control the augmentation. Inverses are built from one factory for the velocity blocks and one for the Schur complement, and reusable state is cached in a ModALPrecondState. See the Navier-StokesPreconditioners" guide page.
