Teko: Block and Physics-Based Preconditioning

Introduction

Teko is a Trilinos package for the development and application of block and physics-based preconditioners. It provides tools to assemble and manipulate block linear operators, to decompose a fully coupled operator into its physical sub-blocks, and to build approximate inverses of those blocks using the full complement of Trilinos solvers and preconditioners (Ifpack2, MueLu, Amesos2, Belos, and others). On top of that infrastructure Teko ships a library of generic block preconditioners (block Jacobi, block Gauss-Seidel, LU 2x2) and physics-based preconditioners for the incompressible Navier-Stokes equations (SIMPLE, LSC, PCD).
