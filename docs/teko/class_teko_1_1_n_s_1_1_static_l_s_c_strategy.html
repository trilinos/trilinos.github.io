Detailed Description

A fixed LSCStrategy built from operators the caller supplies directly.

This is the simplest LSCStrategy: rather than assembling its operators from an inverse library at build time, it is handed the already-formed inverses ( , the Schur-complement inverse, the optional outer stabilization , and the inverse mass matrix) in its constructor and simply returns them. Because nothing is recomputed it is not flexible, but it is useful when the operators are known ahead of time or are produced outside Teko. Compare with the parameter-driven InvLSCStrategy / PresLaplaceLSCStrategy / LSCSIMPLECStrategy variants used by LSCPreconditionerFactory.
