Detailed Description

This class implements the pseudo-block CG iteration, where the basic CG algorithm is performed on all of the linear systems simultaneously.

Author
Heidi Thornquist

This implementation is the same as the default, but is specialized for the Sacado::MP::Vector scalar type to handle break-down when ensemble components are over-solved.
