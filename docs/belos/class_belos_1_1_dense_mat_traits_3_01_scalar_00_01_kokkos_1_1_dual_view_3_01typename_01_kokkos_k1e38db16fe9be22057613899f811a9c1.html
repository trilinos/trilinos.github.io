template<class Scalar, class... Properties>
Scalar * Belos::DenseMatTraits< Scalar, Kokkos::DualView< typename KokkosKernels::ArithTraits< Scalar >::val_type **, Properties... > >::GetRawHostPtr ( DM & dm)
inlinestatic

Returns a raw pointer to the (non-const) data on the host.

Note
We assume that return data in in a column-major format because this is what is expected by LAPACK.
This raw pointer is intended only for passing data to LAPACK functions. Other operations on the raw data may result in undefined behavior!
We assume that getting this pointer to non-const data means that data will be modified. If that is not true, use of this function could result in extra data syncs. The user must NOT hold onto this pointer after any data syncs. If you modify the data again after a sync, the view will not be marked as modified the second time.
