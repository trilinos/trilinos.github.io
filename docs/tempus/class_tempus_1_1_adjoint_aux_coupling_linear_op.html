Detailed Description

template<class Scalar>
class Tempus::AdjointAuxCouplingLinearOp< Scalar >

Coupling block s*op(df/dp) of the W of AdjointAuxSensitivityModelEvaluator.

The auxiliary equations dz/dt - df/dp^T*y = 0 of the adjoint sensitivity equations depend on the adjoint y through -df/dp^T*y, so the block of W of the auxiliary rows and the adjoint columns is -beta*df/dp^T. This operator is s*op(df/dp), with df/dp evaluated by the model in one of the forms of applyDfDpTranspose() (see AdjointSensitivityUtils::evalDfDp()): a linear operator or a Jacobian multivector, applied with op = CONJTRANS, or a gradient multivector, applied with op = CONJ. It maps the residual (f) space of the model to the space of the parameter. Before initialize(), and with a null df/dp, the operator is zero.

The left and right scalings by diagonal matrices are supported, so that the operator can be a block of an operator scaled by a nonlinear solver (e.g., NOX with "Function Scaling" = "Row Sum"); the scalings are stored with the operator, and initialize() resets them.

The row statistics (absolute row and column sums) are reported as zero: the block is left out of the row statistics of W, which are those of its block diagonal. The row scaling of the auxiliary rows (e.g., the inverse row sums) is then uniform, as needed by the scaled identity of the diagonal block of these rows (ScaledIdentityLinearOpWithSolve).
