◆ gemmUsesTeuchosBLAS()

template<typename DeviceType>
bool Intrepid2::Impl::gemmUsesTeuchosBLAS ( )
constexpr

True if PAMatrix<DeviceType,...> issues its GEMMs through Teuchos::BLAS: all host devices, serial or threaded (e.g., OpenMP), with or without KokkosKernels. The host BLAS is the fastest host GEMM available, and calling it directly does not depend on KokkosBlas::gemm's view-layout conditions for using it (a LayoutStride A falls back to the native KokkosKernels implementation, which is several times slower).
