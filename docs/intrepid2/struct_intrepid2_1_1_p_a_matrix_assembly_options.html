◆ defaultsWithEnvironmentOverrides()

PAMatrixAssemblyOptions Intrepid2::PAMatrixAssemblyOptions::defaultsWithEnvironmentOverrides ( )
inlinestatic

Returns default options, overridden by any of the following environment variables (for testing and performance comparison without recompiling):

  • INTREPID2_PAMATRIX_ASSEMBLE_ALGORITHM: "automatic", "unit-columns", or "apply"
  • INTREPID2_PAMATRIX_ASSEMBLE_WORKSPACE_MB: positive number
  • INTREPID2_PAMATRIX_ASSEMBLE_SPARSE_LAST: "automatic", "1" (always), or "0" (never)
  • INTREPID2_PAMATRIX_ASSEMBLE_UNIT_COLUMNS (deprecated; equivalent to INTREPID2_PAMATRIX_ASSEMBLE_ALGORITHM=unit-columns) The variables are read once, on the first call; invalid values throw std::invalid_argument.
