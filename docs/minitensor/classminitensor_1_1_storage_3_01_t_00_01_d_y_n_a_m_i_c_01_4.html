Detailed Description

template<typename T>
class minitensor::Storage< T, DYNAMIC >

Base dynamic storage class. Simple linear access memory model. The number of entries is determined at run time and entries are heap-allocated, allowing resizing. This policy is preferred for research flexibility when sizes are not known at compile time.
