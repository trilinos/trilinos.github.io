Detailed Description

template<typename S, Index M = 2>
class minitensor::Matyas< S, M >

Matyas function NLS: the residual is the gradient of \( 0.26(x_1^2+x_2^2) - 0.48 x_1 x_2 \). Two-dimensional, convex but ill-conditioned; minimum at the origin.
