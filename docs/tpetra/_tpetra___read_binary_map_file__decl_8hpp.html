Detailed Description

Declaration of the scalar-free Tpetra::Experimental::readBinaryMapFile reader.

Tpetra::Experimental::readBinaryMapFile reads a Tpetra::Map from a file written in Tpetra's scalable binary I/O format (see Tpetra::Experimental::BinaryIO). It is a free function templated only on LocalOrdinal, GlobalOrdinal, Node (there is no Scalar), so it is explicitly instantiated on the LGN template scheme. Keeping it in its own translation unit lets its explicit template instantiation stay independent of Tpetra::Experimental::BinaryIO, which is instantiated on the Scalar-LO-GO-Node scheme.
