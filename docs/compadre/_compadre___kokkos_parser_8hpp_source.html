19/*! \class KokkosParser
20 \brief Initializes Kokkos from the command line, or joins the Kokkos already running.
21
22 Kokkos is initialized from the program's command-line arguments whenever they are available, together
23 with the KOKKOS_* environment variables (which Kokkos always reads), and never from arguments that were
24 not given on the command line.
25
26 In C++:
27
28 | Constructor | Kokkos not initialized | Kokkos already initialized |
29 |------------------------------------------------|----------------------------------------|----------------------------|
30 | KokkosParser(argc, argv), KokkosParser(args) | initializes with these arguments | throws std::runtime_error |
31 | KokkosParser(KokkosInitArguments) | initializes with these settings | throws std::runtime_error |
32 | KokkosParser() | warns that command-line arguments are | joins the running Kokkos |
33 | | ignored, and initializes from the | |
34 | | KOKKOS_* environment variables only | |
35
36 - A program that initializes Kokkos itself needs no KokkosParser: GMLS and the other classes use the
37 running Kokkos. Constructing KokkosParser(argc, argv) after that throws, since Kokkos would be initialized
38 twice with arguments in one program. Code without access to the command line uses KokkosParser().
39 - The arguments are copied before they are given to Kokkos, so the caller's argc and argv are not modified
40 (Kokkos::initialize removes the arguments it recognizes).
41 - Kokkos cannot be initialized again once it is finalized, so any KokkosParser constructed after that throws.
42
43 From Python (pycompadre, Python 3.10+), the arguments come from sys.orig_argv, the command line given to the
44 Python executable, which cannot change during a run:
45 - run by the Python executable (sys.orig_argv is not empty): joins the running Kokkos if it is initialized,
46 and otherwise initializes Kokkos with sys.orig_argv;
47 - embedded in a C++ program (sys.orig_argv is empty): behaves as KokkosParser() does in C++.
48 An argument list passed from Python must be sys.argv or sys.orig_argv (the same list or an equal one);
49 any other list throws, since Kokkos is always initialized from sys.orig_argv and the list would be ignored.
50
51 Lifetime: Kokkos started by a KokkosParser is finalized when the last KokkosParser and the last object
52 holding runtime() (a GMLS object, for example) are destroyed, in whatever order. Kokkos initialized outside
53 Compadre is never finalized by Compadre.
54*/
55class KokkosParser {

57private:

64 //! Initializes Kokkos with these settings (combined with the KOKKOS_* environment variables, as Kokkos does).
65 //! Throws if Kokkos is already initialized, or was finalized.
66 KokkosParser(KokkosInitArguments args);
67
68 //! Initializes Kokkos with a copy of the command-line arguments (argc and argv are not modified).
69 //! Throws if Kokkos is already initialized, or was finalized.
70 KokkosParser(int argc, char* args[]);
71
72 //! Initializes Kokkos with the command-line arguments given as strings (argument 0 is the program name).
73 //! Throws if Kokkos is already initialized, or was finalized.
74 KokkosParser(std::vector<std::string> args);
75
76 //! For code without access to the command line: joins the running Kokkos if it is initialized; otherwise
77 //! warns that command-line arguments are ignored and initializes Kokkos from the KOKKOS_* environment
78 //! variables only. Throws if Kokkos was finalized.
79 KokkosParser();
80
81 //! Shares ownership of the Kokkos runtime started by a KokkosParser, so that an object owning Kokkos
82 //! memory can keep Kokkos initialized until it is destroyed: Kokkos is finalized when the last
83 //! KokkosParser and the last holder of runtime() are gone, in whatever order. Empty if Kokkos was not
84 //! started by a KokkosParser (or is not running); then whoever initialized Kokkos finalizes it.
85 static std::shared_ptr<void> runtime();
86
87 // prints Kokkos configuration
88 static std::string status();
89
90 // KokkosParser is not copyable. Deleting the copy constructor explicitly (not only the assignment)
91 // keeps it from being generated implicitly, e.g. by nanobind for pycompadre, which clang reports as
92 // deprecated (-Wdeprecated-copy) when a copy assignment operator is user-declared.
93 KokkosParser(const KokkosParser&) = delete;
94 KokkosParser& operator=( const KokkosParser& ) = delete;
