Detailed Description

Initializes Kokkos from the command line, or joins the Kokkos already running.

Kokkos is initialized from the program's command-line arguments whenever they are available, together with the KOKKOS_* environment variables (which Kokkos always reads), and never from arguments that were not given on the command line.

In C++:

  • A program that initializes Kokkos itself needs no KokkosParser: GMLS and the other classes use the running Kokkos. Constructing KokkosParser(argc, argv) after that throws, since Kokkos would be initialized twice with arguments in one program. Code without access to the command line uses KokkosParser().
  • The arguments are copied before they are given to Kokkos, so the caller's argc and argv are not modified (Kokkos::initialize removes the arguments it recognizes).
  • Kokkos cannot be initialized again once it is finalized, so any KokkosParser constructed after that throws.

From Python (pycompadre, Python 3.10+), the arguments come from sys.orig_argv, the command line given to the Python executable, which cannot change during a run:

  • run by the Python executable (sys.orig_argv is not empty): joins the running Kokkos if it is initialized, and otherwise initializes Kokkos with sys.orig_argv;
  • embedded in a C++ program (sys.orig_argv is empty): behaves as KokkosParser() does in C++. An argument list passed from Python must be sys.argv or sys.orig_argv (the same list or an equal one); any other list throws, since Kokkos is always initialized from sys.orig_argv and the list would be ignored.

Lifetime: Kokkos started by a KokkosParser is finalized when the last KokkosParser and the last object holding runtime() (a GMLS object, for example) are destroyed, in whatever order. Kokkos initialized outside Compadre is never finalized by Compadre.

std::shared_ptr< void > KokkosParser::runtime ( )
static

Shares ownership of the Kokkos runtime started by a KokkosParser, so that an object owning Kokkos memory can keep Kokkos initialized until it is destroyed: Kokkos is finalized when the last KokkosParser and the last holder of runtime() are gone, in whatever order. Empty if Kokkos was not started by a KokkosParser (or is not running); then whoever initialized Kokkos finalizes it.
