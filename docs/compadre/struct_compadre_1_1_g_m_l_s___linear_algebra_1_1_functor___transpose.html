template<typename DeviceType, typename MatrixViewType>
struct Compadre::GMLS_LinearAlgebra::Functor_Transpose< DeviceType, MatrixViewType >

Transpose a matrix of original shape N x M (padded). Result will be M x N.

Parameters
M[in] - number of rows in the result
N[in] - number of columns in the result
b[in/out] - in as rank 3 matrix (num_matrices * N * M), out as rank 3 matrix (num_matrices * M * N)
