Detailed Description

template<class Scalar, class LocalOrdinal, class GlobalOrdinal, class Node>
class MueLu::Details::StructuredRAPKernel< Scalar, LocalOrdinal, GlobalOrdinal, Node >

Specialized numeric kernel for two- and three-dimensional structured RAP.

The implemented path requires two or three dimensions and order-zero interpolation. Its numeric plan is generated from the detected fine stencil and sparse graphs
