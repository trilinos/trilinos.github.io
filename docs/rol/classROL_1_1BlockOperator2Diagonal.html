Detailed Description

template<class Real>
class ROL::BlockOperator2Diagonal< Real >

Provides the interface to apply a 2x2 block diagonal operator to a partitioned vector.

\[ M = \begin{pmatrix} A & 0 \\ 0 & D \end{pmatrix} \]
