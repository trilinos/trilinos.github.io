Detailed Description

template<typename EvalT, typename Traits>
class panzer_stk::GatherRefCoords< EvalT, Traits >

This gathers the physical (mesh) coordinates of a basis's nodes directly from the STK mesh, into a field with one entry per cell/node/spatial dimension.
