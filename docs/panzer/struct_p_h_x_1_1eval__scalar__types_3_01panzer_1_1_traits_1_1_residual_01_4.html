Detailed Description

Declares which scalar types PHX::MDFields may hold for the Residual evaluation type.

Phalanx uses this specialization to determine, for a given evaluation type, which concrete scalar types are legal for fields (in addition to Traits::Residual::ScalarT itself) — here plain bool fields alongside panzer::Traits::RealType.
