Detailed Description

template<typename EvalT>
class panzer::response_bc_adapters::ResponseFactory_BCStrategyAdapter< EvalT >

Adapts a set of named ResponseEvaluatorFactory objects into a single BCStrategy, so responses can be evaluated on a boundary condition side set.

Template Parameters
EvalTthe evaluation type this adapter builds evaluators for.
