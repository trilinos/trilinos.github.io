Detailed Description

template<typename EvalT, typename TRAITS>
class panzer::ReorderADValues_Evaluator< EvalT, TRAITS >

Reorders the ad values of a specified field to match a different unique global indexer.

This is neccessary primarily when gathering with one unique global indexer
and scattering with a second unique global indexer.
