Detailed Description

template<class Real>
class Piro::ThyraProductME_ROL_DynamicConstraint< Real >

ROL dynamic constraint given by one time step of a Tempus stepper.

The residual and its derivatives are computed through the Tempus::StepperOptimizationInterface of the stepper (currently only implemented by the Backward Euler stepper).

The convention is that the adjoint model, if provided, provides the application of the adjoint Jacobian and its inverse; all other operations are provided by the forward model. Without an adjoint model, the adjoint Jacobian is applied as the transpose of the Jacobian, and its inverse is applied by solving with the transposed Jacobian, using the linear solver (and preconditioner) factory of the forward model.

The time steps are solved with the Newton solver of ROL::DynamicConstraint, configured by the "Dynamic Constraint"->"Solve" sublist passed to setSolveParameters(). After each time step the "State Solve Converged" flag of the "Optimization Status" sublist is set to whether all the time steps solved so far in the current trajectory converged; time stamp 1 is the first time step of a trajectory. The state at the time stamp set with setFinalTimeStampIndex() is stored and can be retrieved with getFinalState().
