Detailed Description

template<typename Real>
class Piro::ThyraProductME_TempusFinalObjective< Real >

Reduced objective g(x(T), p) for transient problems, computed with Tempus.

The value is computed by integrating the forward problem with Tempus up to the final time T of the Tempus time step control. The gradient is computed with the Tempus adjoint sensitivity integrator.

The parameters are the product parameter vector (parameter 0) of the model evaluator, so several parameter vectors are supported through Piro::ProductModelEvaluator. The response must be scalar.

If no adjoint model evaluator is provided, Tempus uses an implicit adjoint model, which requires a linear solver that supports transposed solves.

When a forward time integration fails, the "State Solve Converged" flag of the "Optimization Status" sublist is set to false. In this case value() returns the response at the last computed state if an "Objective Recovery Value" is set in "Optimization Status" (see ThyraProductME_ROL_ObservedObjective, which replaces it with the recovery value), and throws otherwise. gradient() always throws.
