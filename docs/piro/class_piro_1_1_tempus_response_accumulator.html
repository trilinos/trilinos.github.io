Detailed Description

template<typename Real>
class Piro::TempusResponseAccumulator< Real >

Tempus observer that computes a "Time Integral" or "Sum Over Times" response during the forward time integration.

  • "Time Integral": J = int_{t0}^{T} g(x(t),p,t) dt, computed with the trapezoidal rule over the accepted time steps.
  • "Sum Over Times": J = sum_k g(x(t_k),p,t_k), where the time steps must end at the times t_k (up to the tolerance). The model is evaluated exactly at the times t_k.
